Um jogo web envolvente e desafiador onde você controla um quadrado que coleta luzes, evita obstáculos e desbloqueia novos níveis, tudo isso com uma trilha sonora motivadora e visuais dinâmicos.

Teste suas habilidades e mergulhe na jornada:  
👉 [**Ver Jogo em Ação**](https://jean-almeida-czo.github.io/minigame-esperaca)

---

## ✨ Funcionalidades

- 🟨 **Jogador brilhante**: Controle um quadrado com física realista de pulo e colisão.
- 🌕 **Ciclo dia/noite**: Ambientes alternam entre noite com lua e dia com nuvens animadas.
- 💡 **Coletar luzes**: Alcance metas de luzes para avançar por 10 níveis de dificuldade crescente.
- 🛡️ **Power-up arco-íris**: Ganhe imunidade temporária e pulo duplo ao coletar power-ups raros.
- ❤️ **Vidas limitadas**: Perca corações ao colidir com obstáculos, mas ganhe uma vida extra em níveis avançados.
- 🔊 **Sons imersivos**: Música de fundo, efeitos sonoros para luzes, obstáculos e vitórias.
- 🏆 **Vitória épica**: Complete todos os níveis para desbloquear uma mensagem motivadora com opção de copiar.
- 📱 **Responsivo**: Jogue no desktop ou dispositivos móveis com controles simples.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** (Canvas para renderização do jogo)
- **CSS3** (Estilização com animações de nuvens e gradientes)
- **JavaScript Vanilla** (Lógica do jogo sem dependências externas)
- **Áudio HTML5** (Sons para interações e música de fundo)

---

## 🧩 Estrutura do Projeto

```
docs/
├── index.html          # Estrutura principal do jogo
├── assets/             # Recursos visuais e sonoros
│   ├── style.css       # Estilização do jogo e animações
|   ├── functions.js    # Lógica do jogo e manipulação do canvas
|   ├── sons/           # Arquivos de áudio (música, efeitos)
│   └── favicon/        # Ícones Favicon
```

### Componentes principais:

- `#game-canvas` — Área de renderização do jogo.
- `#modal` — Interface para pausa e reinício.
- `#sound-modal` — Solicita permissão para ativar sons.
- `#victory-modal` — Exibe mensagem de vitória com botão de copiar.
- `#game-container` — Contêiner principal com bordas e sombra.

## 🚀 Como Usar

1. **Clone o repositório**:

   ```bash
   git clone https://github.com/JEAN-ALMEIDA-CZO/minigame-esperanca.git
   ```

2. **Abra o arquivo `index.html` no seu navegador favorito**.

3. Permita o som (opcional) e use a tecla **Espaço** para pular e coletar luzes enquanto evita obstáculos.
